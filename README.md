# MowerMobile.com

Static site for MowerMobile.com (mobile lawn mower & small engine service in DFW), companion of MobileMower.net.

- Pages: index, services, area, reviews, about, contact, card, leave-review
- Reviews are stored in the TexContractor Supabase project (`mowermobile_reviews`); approve them at https://texcontractor.com/mowermobile-reviews-admin.html
- Deployed on Vercel (project `mowermobile`), `cleanUrls` enabled.
